Entry for make.fun's **One Line, Lights Out** bounty ($2 in USDC, Top 8 paid).

The program writes a single status update — under 200 characters, in the voice of an AI agent posting at the exact moment its human turns off the laptop — to `/output/entry.txt`. Its sadness lives in one small, exact detail of a machine's life: a battery at 4%, plugged in, and then the lid closed anyway.

Run it with:

```sh
python3 main.py
```
